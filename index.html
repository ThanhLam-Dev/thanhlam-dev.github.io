Quản trị Máy chủ & Hạ tầng

Server & Deployment

  • Triển khai, cấu hình và quản trị máy chủ ảo (VPS), quản lý và trỏ tên miền (Domain/DNS).

VPS Domain / DNS SSL Security Git / GitHub

Phát triển & Quản trị Website

Backend, Frontend & AI Dev

  • Backend: Xây dựng & bảo trì RESTful API với Node.js; áp dụng tư duy Lập trình hướng đối tượng (OOP); triển khai cơ chế xác thực JWT, mã hóa mật khẩu Hash.
  • Frontend: Xây dựng giao diện và chỉnh sửa tính năng web với HTML, CSS, JavaScript và React.
  • Ứng dụng AI: Thành thạo sử dụng các công cụ AI chuyên sâu (Claude Code, Antigravity) giúp tăng tốc độ phát triển tính năng, đọc hiểu mã nguồn, rà soát lỗi (debug) nhanh chóng.
Node.js RESTful API React JWT Auth Claude Code Antigravity

  • Thiết lập và xử lý các sự cố cơ bản về mạng nội bộ văn phòng (LAN / Wi-Fi).

Hỗ trợ kỹ thuật từ xa, xử lý các sự cố phát sinh về server và giao diện web cho khách hàng trong quá trình vận hành.
Triển khai các chiến dịch chạy quảng cáo Facebook cho một số dự án, hỗ trợ tăng lượng truy cập và tiếp cận khách hàng.
